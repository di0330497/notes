## 무엇이 문제였나

- 문법 155편이 전부 **6줄에 목표 3개**였다.
  → 한 줄에 문형 예문 하나씩 들어가 **교과서 예문을 이어 붙인 대화**가 됐다.
- 장면 150편은 문장은 맞았지만, 목표를 넣기 위해 갑자기 화제가 튀거나
  같은 사람이 정중체와 반말을 섞는 줄이 있었다.
- N1 45편은 목표 3개를 넣느라 논지가 끊기는 문장이 있었다.

## 어떻게 바꿨나

### 장면 150편
- 10~12줄, 한 장면 = 한 상황. 중간에 다른 화제로 튀지 않게.
- 화자별 말투 고정. 점원·손님·상사는 です・ます, 친구·가족은 だ・よ.
- 목표 없는 줄이 절반 이상. 목표는 대화 흐름에 맞는 자리에만.
- 맞장구·되묻기·말 끊기를 넣어 실제 대화처럼.
- 정중한 장면에 맞지 않는 목표 2개(`ううん`, `ごめんなさい`)는 대화를 살리고 목표에서 뺐다.

### 문법 155편
- 4~6줄, 목표 **1~2개**. 3개를 억지로 넣지 않는다.
- 목표 없는 줄 2줄 이상. 한 줄에 목표 1개.
- 장면·인물·말투를 지키고, 하나의 상황으로 끝난다.
- 목표가 대화에 맞지 않으면 그 목표를 버린다. 자연스러움이 우선.

### N1 45편
- 5~6줄, 목표 2개. 한 사람이 쓴 하나의 글로 이어지게.
- だ・である 체. 예문 나열을 없앴다.

### 한자 314편
- 대화가 아닌 읽기 드릴. 2,136자 전체를 기계 검수.
- 빈 줄 0, 중복 목표 0, 목표-줄 불일치 0, 테마 21종.

## 남은 것

이번 작업은 **AI 기반 일본어 검수**다. 실제 일본어 원어민의 샘플 검수는 아직 없다.

자동 플래그로 남은 경미한 항목:

- 인용문 안의 정중체 (예: 간판의 「辛くありません」, 선생님 말씀 「歩いてください」) — 대화 자체는 반말.
- 짧은 목표 줄 (예: `{本革}です。`, `{いただきます}。`) — 실제 대화에서 자연스러운 한마디.
- 한국어 번역 안의 일본어 인용 (예: `'県'라고 적힌 거`) — 한자를 설명하는 장면이라 의도된 표기.
- `g140` `傷んでないとも限らないよ` — 문법적으로 맞고 대화에서 쓰이지만, 더 쉬운 말로는 `傷んでるかもしれない`가 자연스럽다.
- `g145` `交換するものとしています` — 매장 안내로는 다소 딱딱하다. 목표 문형 유지 때문.
