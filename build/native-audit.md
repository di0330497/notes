# N5~N1 대화 원어민 관점 검수 리포트

## 범위

- 장면 대화 150편
- 문법 마이크로 대화 155편
- 한자 읽기 314편
- N1 읽기 45편
- **합계 664편 전체**

## 방법

1. 664편 전체를 읽고 다음을 확인했다.
   - 말투 일관성 (です・ます / だ・よ)
   - 역할 방향 (손님/점원, 상사/부하, 초대/방문)
   - 질문과 대답의 연결
   - 목표 문형이 장면과 맞는지
   - 한국어 번역에 일본어가 남았는지
2. 자동 플래그: 같은 화자 연속, 레지스터 혼합, 목표-only 짧은 줄, 한 줄 2목표, 한국어 번역 내 일본어, 직원 표현의 화자 오배치.

## 실제로 고친 것

- `sh001` 한국어 번역에 남은 `ですね` 제거
- `g129` `残念さを禁じ得ません` → `残念に思う気持ちを禁じ得ません`
- `g149` `なまじ中途半端に` → `なまじ覚えた`
- `g087` `在庫が少ない気味` → `在庫が不足気味`
- `g128` `感謝に堪えません` → `感謝の念に堪えません`
- `g009` `料理も多いわりに` → `量が多いわりに`
- `g035` `あるんですもの` → `あるんですもん`
- `g093` `上がらせてください` 방향 오류 수정
- `g119` `数字だけを見ているばかりでは` → `数字ばかり見ていては`
- `g145` `店たるもの` → `店として`
- `g095` `時間から言うと` → `時間のことを言えば`
- `g058` `いくつがありますか` → `いくつありますか`
- `g103` `肉をはじめ` → `肉をはじめとして`
- `g050` 우체국 슬랭 → 친구와 택배 이야기로 장면 이동
- `g071` 유카타 친구 → 유카타 대여점(정중한 장면)으로 이동
- `g044` 오사카 시청, `g047` 오사카 은행으로 명시 (간사이ben)
- `sh012` `ほんとですか` → `ほんと？`

## 남은 경미한 어색함

- `sh079` 친구 사이에서 `話しませんか` — `話さない？`가 더 자연스럽지만 목표 문형 유지
- `sh106` 고백에서 `好きです` → `付き合ってくれる？` — 진지한 고백으로 볼 수 있으나 말투 혼합
- `sh136` 친구 사이에서 `でしょうね` — `でしょ`가 더 자연스러움
- `g108` 이별에서 `受け入れかねる` — 문법적으로 가능하지만 감정 장면에서는 다소 딱딱함
- `g131` `この寒さは非常識にもほどがある` — 과장 표현. 틀린 문장은 아님
- `g144` 생선가게 `血まみれ` — 맥락상 가능하나 자극적

## 구조적인 문제 — 원어민이 “이상하다”고 느끼는 핵심

### 1. 문법 155편은 대화가 아니라 문형 드릴

- 전부 **6줄 / 목표 3개**
- 각 줄이 목표 문형 예문 하나씩인 경우가 많다.
- 일본어 문장 자체는 맞지만, 원어민이 읽으면 **“교과서 예문을 이어 붙인 느낌”**이 난다.
- 이 문제는 문장 하나를 고쳐서 해결되지 않는다. 목표를 1~2개로 줄이거나, 4~6줄의 실제 상황극으로 다시 써야 한다.

### 2. N1 읽기 45편은 대화가 아니라 짧은 논평

- 한 사람이 5문장을 말하는 형식.
- 논지는 대체로 연결되지만, 문형 3개를 넣기 위한 문장이 남아 있다.
- 원어민 입장에서는 “읽기 자료”로는 괜찮지만 “대화”는 아니다.

### 3. 한자 314편은 읽기 드릴

- 314편 / 2,136자 전체를 기계 검수 + 샘플 정독.
- 빈 줄 0, 중복 목표 0, 목표-줄 불일치 0.
- 테마 21종, `기타` 0.
- 다만 `今日は「常用3年」の漢字。読める？` 템플릿이 반복되고, 음·훈 읽기 목록이 이어져 **대화 문맥은 아님**.
- 읽기 카드로는 정상이지만, “대화”로 분류하면 원어민은 대화로 느끼지 않는다.

### 4. 장면 150편은 상대적으로 자연스러움

- N5~N3 장면 대화는 대체로 자연스럽다.
- N2~N1 일부 장면은 목표 문형을 넣기 위해 한 줄이 부자연스러운 경우가 남아 있다.

## 결론

- **문장 오류(문법·번역·방향)는 거의 정리됐다.**
- 하지만 **원어민이 “대화가 자연스럽다”고 느끼는 수준**과는 아직 거리가 있다.
- 주된 원인은 틀린 일본어가 아니라 **“목표 문형 3개를 6줄에 넣는 구조”**다.
- 진짜 원어민 수준으로 만들려면 문법 155편을 **목표 1~2개 / 4~6줄**로 다시 쓰거나, 문법 트랙을 대화가 아닌 **예문 드릴**로 명확히 분리해야 한다.

## 원어민 검수

- 이번 검수는 **AI 기반 일본어 자연스러움 검수**다.
- 실제 일본어 원어민 10% 샘플 검수는 아직 없다.
