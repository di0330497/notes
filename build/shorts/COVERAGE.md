# 커버리지 정의와 현재 수치

## 현재 코스

| 트랙 | 편수 | 줄 수 | 목표 |
|---|---:|---:|---:|
| 장면 대화 | 150 | 1,756 | 496 |
| 문법 대화 | 155 | 881 | 310 |
| 상용한자 읽기 | 314 | 1,873 | 2,136 |
| N1 읽기 | 45 | 243 | 90 |
| **합계** | **664** | **4,753** | **3,032** |

## 이번에 목표 수가 줄어든 이유

자연스러운 대화를 위해 **한 대화에 목표를 1~2개만** 남겼습니다.

- 문법 155편: 3목표 → **2목표** (465 → 310, 155개 제외)
- N1 읽기 45편: 3목표 → **2목표** (135 → 90, 45개 제외)
- 장면 150편: 3목표 유지. 단 정중한 장면에 맞지 않는 `ううん`, `ごめんなさい` 2개는 대화를 자연스럽게 바꾸면서 제외 (498 → 496)

제외된 항목은 사전·백데이터에는 남아 있지만 **코스 목표·커버리지에는 포함되지 않습니다.**

## 검증

- 장면: 496슬롯 / 490고유 (98.8%)
- 문법: 310 / 310 (100%)
- 한자: 2,136 / 2,136 (100%)
- N1 읽기: 90 / 90 (100%)
- 구조 QA: 빈 줄 0, 중복 목표 0, 괄호 불균형 0, 한국어 누락 0
- 문법 줄 수 4~6, 장면 7~14, N1 4~6, 한자 4~7

## 95%의 의미

현재 수치는 **코스에 남긴 목표 기준**입니다.

- 전체 백데이터 5,351개 기준으로는 3,032개 = **56.7%**
- 상용한자 2,136자는 **대표 음/훈** 기준 100%
- 전체 8,649읽기 기준은 아님
- 일본어 원어민의 실제 검수는 아직 없음

즉 “자연스러운 코스 3,032목표”는 정리됐지만,
“백데이터 전체 95%를 대화로 덮는 것”은 별개의 목표이며 아직 달성하지 않았습니다.

## 대화 자연스러움 작업

- 장면 150편: 10~12줄로 전면 재작성. 한 상황이 처음부터 끝까지 이어지게.
- 문법 155편: 4~6줄, 목표 1~2개, 목표 없는 줄 2줄 이상으로 전면 재작성.
- N1 45편: 5~6줄, 목표 2개, 하나의 논지로 이어지는 글로 재작성.
- 한자 314편: 읽기 드릴. 대화가 아니므로 문장만 점검(빈 줄·중복·읽기 목록).
