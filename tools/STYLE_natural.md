# 대화를 「실제 생활 일본어」로 다시 쓰는 지침

이 문서는 `j/2b10e90aebe237af55/data/dialogue-1.js`, `dialogue-2.js`, `dialogue-3.js`
안의 서사 대화(d01~d80)를 교과서 문장이 아니라 **실제 일본인이 일상에서 주고받는 말**로
고쳐 쓰기 위한 규칙이다. 새로 대화를 지어내지 말고, 지금 있는 장면·인물·태그를 지키면서
**말투와 문장만** 자연스럽게 바꾼다.

## 0. 절대 지켜야 하는 형식 (하나라도 깨지면 사이트가 망가진다)

1. 파일 구조와 필드 이름(`id` `title` `scene` `place` `lv` `chars` `lines` `points` `tags`)은
   그대로 둔다. 대화 순서·개수도 바꾸지 않는다.
2. `lines[].s` 안의 표기법:
   - `[漢字|よみ]` = 후리가나. **새로 쓴 문장의 모든 한자에도 반드시 읽기를 달아야 한다.**
     읽기에는 가나와 `ー`만 쓴다. 예: `[今日|きょう]`, `[一人|ひとり]`, `[珈琲|コーヒー]`(X) —
     외래어 표기는 괄호 없이 그냥 쓴다.
   - `{...}` = 그 대화의 tags 문형·표현·한자가 실제로 나오는 자리를 표시하는 밑줄.
     `{[漢字|よみ]}` 처럼 겹쳐 써도 된다. **tags 에 적힌 항목이 반드시 한 줄에는 나오게 유지한다.**
   - 대괄호 안에 가나만 있으면(`[えっと]`) 강조 표시가 된다.
   - `{}` `[]` `|` 는 짝이 맞아야 한다. 문장 안에 홑따옴표·반각 쉼표·마침표를 쓰지 않는다
     (일본어 문장부호 `、。「」！？`만).
3. `lines[].ko` 는 한국어 번역. 자연스러운 한국어로, 일본어와 뜻이 맞아야 한다.
4. `points` · `tags` 는 내용만 손보고 형식은 유지한다. tags 의 문형 문자열을 임의로 바꾸지 않는다.
5. 줄 수는 늘려도 **대화당 최대 +2줄**. 정보(숫자·요금·시간·개수)는 지우지 않는다.

## 1. 말투(register)를 장면에 맞춘다 — 가장 중요

지금 대화는 **모두가 완벽하게 정중체**라서 교과서처럼 들린다. 장면과 상대에 따라 나눈다.

| 상대 | 말투 | 예 |
|---|---|---|
| 친구·동기·후배·선배(사적) | 보통체 + 종조사 | 〜だよ / 〜じゃん / 〜かな / 〜けど / 〜って / 〜でしょ |
| 가족·연인 | 보통체, 더 짧게 | 〜の？ / 〜だね / 〜してきて |
| 손님→점원 | 정중체지만 짧게 | 〜お願いします / 〜もらえますか / 〜でいいです |
| 점원→손님 | 정중체 + 관용구 | お決まりですか / 少々お待ちください / ご一緒ですか |
| 회사(사수·상사) | 정중체 + 완곡 | 〜かと思います / 〜ていただけますか / 〜みたいです |

- 친구끼리인데 `です・ます`를 쓰고 있으면 고친다. 회사·접객 장면인데 너무 딱딱하면 줄인다.
- 손님과 점원이 **똑같이** 정중한 긴 문장을 주고받으면 부자연스럽다. 점원은 짧고 관용적으로.

## 2. 실제 회화의 표면 특징을 넣는다

- **필러 / 머뭇거림**: あー、えっと、なんか、その、あの、うーん、あ、そうだ
- **맞장구(相づち)**: へえ、マジで？、そっか、だよね、なるほど、いいね、たしかに、うんうん
- **문장 끝 흐림·생략**: 〜けど、〜んだけど、〜かな、〜かも、〜みたい、〜って、〜じゃん、〜でしょ、〜し
- **축약**: 〜ている→〜てる / 〜ておく→〜とく / 〜てしまう→〜ちゃう / 〜という→〜って /
  〜なければ→〜なきゃ / 〜のではない→〜んじゃない / 〜ては→〜ちゃ
- **되묻기**: え、〜？ / 〜って？ / 〜の？
- **주어·조사 생략**, 도치, 짧은 한마디
- 감정·실수·농담·불평을 조금씩 섞는다(너무 매끄럽게 정보만 오가면 AI 티가 난다)

## 3. 피해야 할 것 (지금 문제인 부분)

- 완벽한 Q→A 교환. 정보가 하나도 안 빠진 채 또박또박 이어짐.
- `〜は何ですか？` `〜してください` `〜ことができます` 식 교과서 틀 반복.
- 서비스 장면에서 점원이 규정을 길게 설명(`〜となっております` 남발). → 짧은 관용구로.
- 숫자·요금·시간을 매번 정확히 끝까지 읽어줌. → 자연스럽게 줄이거나 생략.
- 감탄사·맞장구 없이 곧바로 용건.
- 한국어 직역투·번역체: 「〜することができます」「〜という意味です」「〜が必要です」 남발.

## 4. 좋은 변환 예시

**d01 (카페, 손님↔점원)**

전(교과서):
```
aki:  いらっしゃいませ！何名様ですか？
jihu: 一人です。窓際の席に座ってもいいですか？
aki:  はい、どうぞ！ご注文はお決まりですか？
jihu: えっと、ブレンドコーヒーを一つと、チーズケーキを二つお願いします。
```

후(실제):
```
aki:  いらっしゃいませー。お一人ですか？
jihu: あ、はい、一人です。[窓際|まどぎわ]の[席|せき]、[空|あ]いてますか？
aki:  どうぞ、あちらへ。ご[注文|ちゅうもん]は？
jihu: えっと、ブレンドひとつと、チーズケーキ[二|ふた]つ、お[願|ねが]いします。
```
→ 점원은 짧게, 손님은 `えっと`로 머뭇거리고, `お一人ですか？`처럼 줄인다. 태그 문형
`～てもいいですか` 가 필요한 대화라면 그 줄만 살려 둔다.

**친구끼리 (d24 같은 장면)**

전: `明日、映画を見に行きませんか？`
후: `ねえ、明日ヒマ？映画でも行かない？`

전: `それはいいアイデアですね。何時にしますか？`
후: `いいね！何時にする？`

## 5. 작업 방법

- 파일 전체를 새로 쓰지 말고, **어색한 줄만 골라 `edit` 로 바꾼다.** 손대지 않아도 되는 줄은 그대로 둔다.
- 각 대화에서 최소 절반 이상의 줄은 손보는 것이 목표다. 특히 정보 설명조·정중체 남발 줄.
- 바꾼 뒤 반드시 `node tools/check_dialogue_markup.cjs` 를 돌려 통과시킨다.
- tags 에 적힌 문형·표현·한자가 그 대화 안에 실제로 남아 있는지 눈으로 확인한다.
